Over Mountain Time (VS)

Mountain Time geldt voor Denver, Salt Lake City en Calgary. UTC−7 in de winter (MST), UTC−6 in de zomer (MDT). Arizona blijft het hele jaar op MST.

MST omrekenen naar een andere zone

MST → ESTMST → EDTMST → CSTMST → CDTMST → MDTMST → PSTMST → PDTMST → AKSTMST → HSTMST → UTCMST → GMTMST → BSTMST → CETMST → EETMST → MSKMST → GSTMST → ISTMST → PKTMST → WIBMST → SGTMST → HKTMST → PHTMST → JSTMST → KSTMST → AESTMST → NZSTMST → SASTMST → BRT
