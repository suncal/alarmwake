Despre Ora de vară britanică

BST este UTC+1, în vigoare în Regatul Unit de la sfârșitul lui martie până la sfârșitul lui octombrie.

Convertește BST în alt fus

BST → ESTBST → EDTBST → CSTBST → CDTBST → MSTBST → MDTBST → PSTBST → PDTBST → AKSTBST → HSTBST → UTCBST → GMTBST → CETBST → EETBST → MSKBST → GSTBST → ISTBST → PKTBST → WIBBST → SGTBST → HKTBST → PHTBST → JSTBST → KSTBST → AESTBST → NZSTBST → SASTBST → BRT
